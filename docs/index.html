Run from source

Requirements: Python 3.10+ and pygame-ce.

git clone https://github.com/YOUR_USERNAME/retroRally.git
cd retroRally
pip install pygame-ce
python3 rally_game.py

What’s in the game

  • Login or sign up (local accounts)
  • 8-lap oval — first to the line wins
  • Tuning shop — speed upgrades & difficulty presets
  • 7 car chassis — grip, accel & speed tradeoffs
  • Paint, decals & setup sliders
  • Multiplayer tab — host on LAN, seek players, replace AI slots

Controls

  • WASD — drive
  • R — reset race
  • Esc — back / quit

Publish this page on GitHub Pages

  3. Under Build and deployment, set Source to Deploy from a branch.
  4. Branch: main (or master), folder: /docs.
  5. Save — your site will be at https://YOUR_USERNAME.github.io/retroRally/
